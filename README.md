# Bank Loan Analysis – SQL and Power BI

## Project Overview

This project focuses on analysing a bank loan dataset using SQL and Power BI to identify trends in loan distribution, borrower behaviour, repayment patterns, and credit risk. SQL queries were executed using SQLite through DBeaver to extract, filter, and analyse loan data, while Power BI was used to create interactive visualisations. The analysis aims to provide actionable business insights to help bank stakeholders understand lending patterns, identify high-risk borrower segments, and support informed loan evaluation and approval decisions.

## Objectives

- Explore and understand the structure of the bank loan dataset.
- Analyse loan distribution based on purpose, term, and geographic location.
- Examine interest rate patterns across different borrower profiles.
- Evaluate loan distribution across credit grades and sub-grades.
- Identify default patterns and potential credit risk indicators.
- Investigate relationships between employment length and loan repayment behaviour.
- Present key findings through SQL analysis and Power BI visualisations.
